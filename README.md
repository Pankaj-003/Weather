# 🌍 Smart Weather App

A beautiful, responsive weather application built with **React**, styled with **CSS**, and powered by the **OpenWeatherMap API**. Users can enter any city, town, or village name to get real-time weather conditions including temperature, humidity, weather description, and location coordinates.

---

## 🚀 Features

- 🔍 Search weather by city or location name
- 🌤️ Displays temperature, humidity, description, and icon
- 🎨 Smooth animations and elegant UI
- 📱 Fully responsive on all screen sizes
- ⚡ Fast and lightweight
